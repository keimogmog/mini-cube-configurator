mini cube Configurator

Shared browser Configurator for mini cube devices. MP9 is the first supported model (MIDI Channel and pad CC numbers). Use Chrome or Edge on this HTTPS page or localhost. Web MIDI with SysEx is required. Firmware Update plus Connect to Bootloader is a WebUSB PoC. UF2 Flash Plan is a browser dry run first. Write UF2 uses only a Dry Run ACCEPT plan (known MP9_V1.ino.uf2). Reboot stays disabled until verify passes.

Bootloader (WebUSB PoC)

        

          After Firmware Update, MP9 appears as RPI-RP2. Connect to Bootloader claims the ROM
          PICOBOOT interface. Test PICOBOOT Communication then sends PC_READ of 16 ROM bytes at
          0x00000000. UF2 Flash Plan parses a known MP9 UF2. If PICOBOOT is claimed, Dry Run also
          reads EEPROM[0x101FF000] (256 bytes) and keeps that probe. Write UF2 then erases and
          programs only the accepted plan range, verifies every page, and leaves Reboot disabled
          until verify passes. EEPROM is never in the erase/write range.

UF2 Flash Plan / Dry Run

          
Dry Run — Flash not modified

          

            Choose a known-good MP9_V1.ino.uf2. Analyze UF2 (Dry Run) first. Write UF2
            is enabled only after ACCEPT, bootloader claim, and an EEPROM probe. It erases the
            accepted 4 KiB sectors, writes the accepted 256-byte pages, then read-back verifies.
            Reboot is a separate step after verify. Erase flash stays unavailable on its own so
            this UI cannot send an arbitrary address erase.
